# 📊 Power BI E-Commerce Analysis Dashboard

## 📌 Project Overview

This project is an interactive **E-Commerce Analysis Dashboard built using Microsoft Power BI**.

The dashboard analyzes sales, profit, orders, customers, regional performance, category performance, and shipping costs. It helps transform raw e-commerce data into meaningful business insights through interactive visualizations, KPIs, maps, charts, and slicers.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall e-commerce sales performance
- Track total sales and profit
- Analyze total orders and customers
- Compare performance across different regions
- Analyze sales and profit by product category
- Analyze shipping costs and shipping efficiency
- Identify major profit-driving categories and products
- Identify regional performance differences
- Provide actionable business insights

---

## 🏢 Business Problem

E-commerce businesses generate large amounts of sales and operational data. It can be difficult to understand:

- Which categories generate the most sales?
- Which categories generate the most profit?
- Which region performs the best?
- How many orders and customers are being handled?
- How much does shipping affect profitability?
- Which states and products contribute significantly to profit?
- Where can the business improve its performance?

This Power BI dashboard provides an interactive solution to answer these questions.
